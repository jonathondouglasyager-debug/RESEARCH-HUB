# RESEARCH-HUB

Browser-based research toolkit — 4 standalone HTML apps for searching, visualizing, and analyzing research datasets. No server or build step required.

## Tools

| App | Description |
|-----|-------------|
| **[master_research_hub.html](master_research_hub.html)** | Navigation and overview dashboard |
| **[master_research_hub_SEARCH.html](master_research_hub_SEARCH.html)** | CSV loading, text search, and data export |
| **[master_research_hub_PRO.html](master_research_hub_PRO.html)** | Advanced search with boolean/fuzzy queries, date filters, saved searches, and D3.js network visualization |
| **master_research_hub_ULTIMATE** | All-in-one hub with Claude API integration, PDF processing (PDF.js), OCR (Tesseract.js), and drag-and-drop file handling |

## Datasets

- `Atmospheric_Infrastructure_Actors.csv` — Corporate and government actors database
- `Flight_Tracking_Investigation.csv` — Flight tracking research data
- `Geoengineering_Legislation.csv` — State-level legislation tracking
- `Weather_Modification_Timeline.csv` — Historical timeline data

## Usage

Open any HTML file in a modern browser — that's it. No installation needed.

The ULTIMATE version requires an [Anthropic API key](https://console.anthropic.com/) for AI-powered analysis features.
